# Frontend Mentor - Product preview card component

A responsive product showcase card built for the [Frontend Mentor](https://www.frontendmentor.io) Product Preview Card challenge, emphasizing the featured product details, pricing, and polished hover/focus states to match the supplied design.

## Screenshot

![Product preview card UI](./preview.jpg)

## Overview

This project recreates the Product Preview Card challenge by translating the provided style guide into semantic HTML and modern CSS. It concentrates on presenting product imagery, descriptions, pricing, and call-to-action states with responsive spacing and typography. Use the repo to inspect structure, tweak styles, or extend interactions; contributions or suggestions are welcome via issues or pull requests.

## Built With

- Semantic HTML5 markup
- CSS custom properties & Flexbox
- Mobile-first workflow
- Vanilla JavaScript _(optional, only if you added interactions)_
